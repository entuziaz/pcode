Lagos Pilot Developer Docs

pCode Addressing MVP

Type a street keyword (like Awolowo), or enter postcode prefix (100, 101, 102...), then select a street.

Pilot limitations: this MVP currently uses Lagos-only source data with centroid-based geolocation guesses for fast validation.

API Quick Checks

  • GET /health
  • GET /search?query=awolowo
  • GET /postcode/100/streets
