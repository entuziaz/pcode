API Reference

Base URL: http://localhost:3000

  • Content-Type: application/json
  • CORS: enabled (*)
  • Methods: GET, POST, OPTIONS

GET /postcode/:code/streets

Lookup streets by 3-digit prefix or 6-digit postcode.

  • Accepts 100 or 100281
  • Non-digit characters are stripped
  • Legacy alias also works: GET /postcode/:code
curl "http://localhost:3000/postcode/100/streets"

# Invalid-length sample
curl "http://localhost:3000/postcode/12/streets"

GET /search?query=<text>&limit=<n>

Ranked partial matching for streets, areas, and LGAs.

ParamTypeRequiredNotes
querystringYesFree-text query
limitnumberNoDefault 20, max 100
 
curl "http://localhost:3000/search?query=awolowo&limit=5"

POST /reverse-geocode

Returns nearest structured address guess from available geo data.

curl -X POST "http://localhost:3000/reverse-geocode" \
  -H "Content-Type: application/json" \
  -d '{"lat":6.5,"lng":3.35}'

GET /health

Service and dataset health check.

curl "http://localhost:3000/health"

Errors

  • 400: invalid lat/lng payload
  • 404: no geocoded records or unknown route
  • 405: unsupported method
  • 500: server/runtime issue
